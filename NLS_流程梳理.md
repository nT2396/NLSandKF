## 二、NLS 迭代详细流程图

```
                              ┌─────────────┐
                              │  开始迭代    │
                              └──────┬──────┘
                                     │
                                     ▼
                        ┌────────────────────────┐
                        │  p_u = 初始猜测 (偏移)  │
                        │  例: 真值 + 50km 随机   │
                        └────────────┬───────────┘
                                     │
              ┌──────────────────────┘
              │
              ▼
    ┌──────────────────┐
    │   for iter=1:50  │ ◄──────────────────────────────┐
    └────────┬─────────┘                                 │
             │                                            │
             ▼                                            │
    ┌──────────────────────────────────────┐              │
    │  Step A: 计算理论多普勒 f_model      │              │
    │                                      │              │
    │  l_vec = P_sat - p_u       (NK×3)    │              │
    │  dist  = ||l_vec||         (NK×1)    │              │
    │  v_r   = (V_sat·l_vec)/dist(NK×1)    │              │
    │                                      │              │
    │  f_model = -(fc/c) * v_r   (NK×1)    │              │
    │  ┌──────────────────────────────┐    │              │
    │  │ 代入: 当前猜测的 p_u         │    │              │
    │  │ 输出: "如果接收机在 p_u,     │    │              │
    │  │       多普勒应该是多少"     │    │              │
    │  └──────────────────────────────┘    │              │
    └────────────────┬─────────────────────┘              │
                     │                                    │
                     ▼                                    │
    ┌──────────────────────────────────────┐              │
    │  Step B: 计算残差 df                 │              │
    │                                      │              │
    │  df = y_meas - f_model     (NK×1)    │              │
    │  ┌──────────────────────────────┐    │              │
    │  │ y_meas: 接收机实际测量的f_D  │    │              │
    │  │ f_model: 理论预测的f_D      │    │              │
    │  │ df > 0 → 猜测位置偏了       │    │              │
    │  └──────────────────────────────┘    │              │
    └────────────────┬─────────────────────┘              │
                     │                                    │
                     ▼                                    │
    ┌──────────────────────────────────────┐              │
    │  Step C: 收敛判断                    │              │
    │                                      │              │
    │  if norm(df) < 1e-9 → 跳出循环      │              │
    │  ┌──────────────────────────────┐    │              │
    │  │ 残差趋零 = 模型和测量一致    │    │              │
    │  │ = 猜测位置≈真实位置          │    │              │
    │  └──────────────────────────────┘    │              │
    └────────────────┬─────────────────────┘              │
                     │                                    │
                     │ (未收敛, 继续)                      │
                     ▼                                    │
    ┌══════════════════════════════════════┐              │
    ║  Step D: 计算 Jacobian H (NK×3)     ║              │
    ║           (第150-152行)              ║              │
    ║                                      ║              │
    ║  ① v_dot_l = sum(V_sat .* l_vec, 2) ║              │
    ║     ↓ v_s · l  (速度·视线 点积)      ║              │
    ║                                      ║              │
    ║  ② l_dot_term = (v_dot_l/dist²)·l   ║              │
    ║     ↓ Jacobian 的修正项              ║              │
    ║                                      ║              │
    ║  ③ H = (fc/(c·dist)) · (V_sat - term)║              │
    ║     ↓ 完整 Jacobian                  ║              │
    ║                                      ║              │
    ║  ┌──────────────────────────────┐    ║              │
    ║  │ H 的物理含义:                │    ║              │
    ║  │ "p_u 沿 x/y/z 移动 1m,      │    ║              │
    ║  │  每个观测的 f_D 变化多少 Hz" │    ║              │
    ║  └──────────────────────────────┘    ║              │
    └════════════════┬═════════════════════┘              │
                     │                                    │
                     ▼                                    │
    ┌──────────────────────────────────────┐              │
    │  Step E: 求解修正量                  │              │
    │                                      │              │
    │  dp = H \ df               (3×1)     │              │
    │                                      │              │
    │  等价于: dp = (HᵀH)⁻¹Hᵀ · df       │              │
    │  ┌──────────────────────────────┐    │              │
    │  │ 泰勒线性化方程:              │    │              │
    │  │                              │    │              │
    │  │   H    ·   Δp   =   Δf      │    │              │
    │  │ (NK×3)   (3×1)    (NK×1)    │    │              │
    │  │                              │    │              │
    │  │ Jacobian × 位置修正 = 残差   │    │              │
    │  └──────────────────────────────┘    │              │
    └────────────────┬─────────────────────┘              │
                     │                                    │
                     ▼                                    │
    ┌──────────────────────────────────────┐              │
    │  Step F: 更新位置                    │              │
    │                                      │              │
    │  p_u = p_u + dp'          (1×3)      │              │
    │  ┌──────────────────────────────┐    │              │
    │  │ dp_norm = ||dp||             │    │              │
    │  │ 打印: iter, df, dp_norm, err │    │              │
    │  └──────────────────────────────┘    │              │
    └────────────────┬─────────────────────┘              │
                     │                                    │
                     └────────────────────────────────────┘
                     (回到 for 循环, 用新的 p_u 重算)
```

## 四、一次完整迭代的数据流

```
输入                  处理                     输出
────                  ────                     ────

P_sat (NK×3) ───┐
V_sat (NK×3) ───┤
p_u (1×3)    ───┤    ┌─────────────┐
                  ──→│ l_vec       │──→ NK×3  (视线向量)
                     │ = P_sat-p_u │
                     └─────────────┘
                            │
                            ▼
                     ┌─────────────┐
                     │ dist        │──→ NK×1  (距离)
                     │ = ||l_vec|| │
                     └─────────────┘
                            │
              ┌─────────────┴─────────────┐
              ▼                           ▼
       ┌─────────────┐            ┌─────────────┐
       │ v_r         │            │ v_dot_l     │
       │=(V·l)/dist  │            │ = sum(V·l)  │
       └──────┬──────┘            └──────┬──────┘
              │                          │
              ▼                          ▼
       ┌─────────────┐            ┌─────────────┐
       │ f_model     │            │ l_dot_term  │
       │ = -(fc/c)·vr│            │ = v·l/d² · l│
       └──────┬──────┘            └──────┬──────┘
              │                          │
              ▼                          ▼
y_meas ──→ ┌─────────┐           ┌─────────────┐
(NK×1)    │ df =    │           │ H = fc/(c·d)│
           │ y_meas  │           │  ·(V - term)│
           │ -f_model│           └──────┬──────┘
           └────┬────┘                  │
                │                       │
                └───────────┬───────────┘
                            │
                            ▼
                     ┌─────────────┐
                     │ dp = H \ df │──→ 3×1  (位置修正量)
                     └──────┬──────┘
                            │
                            ▼
                     ┌─────────────┐
                     │ p_u += dp'  │──→ 1×3  (更新后位置)
                     └─────────────┘
```

## 六、代码行号 ↔ 步骤对应表

| 代码行 | 操作 | 变量 | 维度 |
|--------|------|------|------|
| 83-93 | 堆叠所有卫星×时刻的数据 | `P_sat`, `V_sat`, `y_meas` | NK×3, NK×3, NK×1 |
| 105-108 | 设置初始猜测 | `p_u` | 1×3 |
| **129** | **视线向量** | `l_vec = P_sat - p_u` | NK×3 |
| **130** | **距离** | `dist = vecnorm(l_vec)` | NK×1 |
| **131** | **径向速度** | `v_r = (V·l)/dist` | NK×1 |
| **132** | **理论多普勒** | `f_model = -(fc/c)·v_r` | NK×1 |
| **135** | **残差** | `df = y_meas - f_model` | NK×1 |
| **150** | **速度·视线 点积** | `v_dot_l = sum(V·l)` | NK×1 |
| **151** | **Jacobian 修正项** | `l_dot_term = (v_dot_l/dist²)·l` | NK×3 |
| **152** | **Jacobian 矩阵** | `H = (fc/(c·dist))·(V - term)` | NK×3 |
| **155** | **求解位置修正量** | `dp = H \ df` | 3×1 |
| **160** | **更新位置** | `p_u = p_u + dp'` | 1×3 |
